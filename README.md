# ПромВент — Сайт-визитка для компании по ремонту промышленной вентиляции, автоматики и кондиционеров

## 📋 О проекте
Корпоративный сайт для компании, специализирующейся на ремонте промышленной вентиляции, автоматики и кондиционеров. Проект разрабатывается в рамках лабораторных работ по курсу "Коллективная разработка ПО".

**Цель проекта:** Создать сайт с одной страницей для привлечения новых клиентов, демонстрации экспертизы компании и сбора заявок.

## 🚀 Быстрый старт (для разработчиков)
```bash

git clone https://github.com/julia-myaso00/promvent-site

# Перейти в папку проекта
cd promvent
```


Краткая инструкция по запуску проекта на другом компьютере
________________________________________
Шаг 1. Установите PHP
Скачайте: https://windows.php.net/download/ (версия PHP 8.2, Thread Safe x64)
Установка:
1.	Распакуйте архив в C:\php
2.	Добавьте C:\php в переменную PATH:
o	Панель управления → Система → Дополнительные параметры → Переменные среды
o	Найдите Path → Добавить C:\php
Проверка:
```cmd
php -v
```
________________________________________
Шаг 2. Установите Ollama (ИИ)
Скачайте: файл OllamaSetup.exe (в архиве)
Установите и запустите. Значок (ламы) появится в трее.
 
Скачайте речевую модель:
```cmd
ollama pull llama3.2:3b
```
Проверка:
```cmd
ollama list
 ```
________________________________________
Шаг 3. Скопируйте проект
Скопируйте папку сайт в любую удобную папку на новом компьютере.
У меня было:
```C:\Users\Yulius-Krolik\Desktop\Юя\КнАГУ\3 курс\6 семестр\КРПО (Коллективная Разработка Программного Обеспечения)```
________________________________________
Шаг 4. Запустите сервер
Откройте командную строку в папке с проектом:
```cmd
cd "путь_к_папке\сайт"
php -S localhost:8000
```
 У меня было:
```
cd "C:\Users\Yulius-Krolik\Desktop\Юя\КнАГУ\3 курс\6 семестр\КРПО (Коллективная Разработка Программного Обеспечения)\сайт"
php -S localhost:8000
```
________________________________________
Шаг 5. Откройте в браузере
|   Страница  |              Адрес                     |
|-------------|----------------------------------------|
|Главный сайт	| http://localhost:8000                  |
|Админ-панель	| http://localhost:8000/admin/leads.php  |
Логин: admin
Пароль: PromVent2026
________________________________________
Проблемы и решения
|          Проблема          |                 	Решение                  |
|----------------------------|-------------------------------------------|
|php не распознан            |	Не установлен PHP или не добавлен в PATH |
|Ошибка подключения к Ollama |	Запустите Ollama (значок в трее)         |
|Белая страница              |	Проверьте, что файл index.php существует |
|Ошибка 404                  |	Проверьте путь к папке с проектом        |
________________________________________
Всё! Проект работает.
